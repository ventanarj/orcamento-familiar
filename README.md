# orcamento-familiar

Aplicação web simples para acompanhar o orçamento familiar. A tela inicial apresenta o saldo do mês, próximas contas, metas da família e atalhos rápidos para registrar receitas ou despesas. O layout é responsivo para desktop e celular.

## Como rodar

1. Certifique-se de ter o Node.js instalado (não há dependências externas).
2. Execute o servidor estático:

```bash
npm start
```

3. Abra o navegador em [http://localhost:4173](http://localhost:4173).
